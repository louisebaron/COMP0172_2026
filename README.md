# COMP0172_2026
AI for Biomedicine and Healthcare 2026–2027

This repository contains the lab sessions for the UCL module **COMP0172 AI for Biomedicine and Healthcare**. Each lab is in its own folder with a notebook and any data it needs.

## Labs
- **Lab 1**: Heart disease prediction (EDA, preprocessing, classical ML)


## Usage
You can run the notebooks in two ways:

- **Google Colab (recommended, no installation):** go to https://colab.research.google.com/, choose "GitHub", and paste the URL of this repo. Then pick the notebook you want. Note: Colab only opens the notebook, not the data. Upload the lab's data file (e.g. `heart_failure.csv`) via the "Files" panel on the left before running.
- **Locally:** clone the repo and run the notebooks with Jupyter. Make sure you have an environment with the required packages installed.
  
## Solutions
Solution notebooks are added to each lab folder after the session.
